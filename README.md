# Login Form

This is a login form I made using HTML and Tailwind CSS.

## Live Link
https://loginformtai.netlify.app/

## What I Used

- HTML - for the form structure
- Tailwind CSS - for styling
- VS Code - to write the code
- GitHub - to save and share the project
- Netlify - to put it online

## What's in the Form

- Username input
- Password input
- Remember me checkbox
- Forgot password link
- Sign in button
- Sign up link
