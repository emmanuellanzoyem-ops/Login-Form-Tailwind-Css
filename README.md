# Login Form Tailwind CSS

A beautiful, responsive login form built with **Tailwind CSS**. Features smooth animations, focus states, and a professional design.

## 🌐 Live Demo

Check out the live version here: **[https://loginformtai.netlify.app/](https://loginformtai.netlify.app/)**

## ✨ Features

- 🎨 **Modern Design** - Built entirely with Tailwind CSS
- 📱 **Responsive** - Looks great on all screen sizes
- ⚡ **Smooth Animations** - Hover and focus state transitions
- 🔐 **User-Friendly** - Includes "Remember me" checkbox and forgot password link
- 🎯 **Sign-Up Link** - Ready for new user registration
- ✅ **Production-Ready** - Clean, optimized code

## 🛠️ Technologies Used

- **HTML5** - Semantic markup
- **Tailwind CSS** - Utility-first CSS framework
- **PostCSS** - CSS processing

## 🚀 Getting Started

### Prerequisites
- Node.js and npm installed

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/emmanuellanzoyem-ops/Login-Form-Tailwind-Css.git
   cd Login-Form-Tailwind-Css
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Build Tailwind CSS**
   ```bash
   npm run build
   ```
   Or for watch mode:
   ```bash
   npm run watch
   ```

4. **Open in browser**
   - Simply open `index.html` in your browser
